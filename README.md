# Excel report automation (demo)

A small Python tool that takes the monthly order exports a business already has
(CSV and Excel files from different systems, in different formats) and turns them
into **one clean, formatted Excel report** in a couple of seconds.

It is a work sample. The input data is synthetic: a fictional coffee roaster,
generated by `tools/make_sample_data.py`.

## The problem it solves

Someone spends a few hours every month copying exports into one spreadsheet,
fixing dates and number formats, removing duplicates and building the same
pivot tables again. The exports never quite match:

| File | Format | Quirks |
|---|---|---|
| `webshop_orders_2026-07.csv` | comma separated | ISO dates, `169.00` prices |
| `regnskap_ordre_2026-08.csv` | semicolon, Norwegian headers | `14.08.2026` dates, `1 234,50` prices, BOM |
| `orders_september_2026.xlsx` | Excel | other column names, real Excel dates |

On top of that: orders exported twice, product names typed in different ways
(`ethiopia yirgacheffe 250 g` vs `Ethiopia Yirgacheffe 250g`), missing
quantities, an impossible date (31 February) and a price written as `n/a`.

## What it does

1. Reads every `.csv` and `.xlsx` file in a folder, detecting the delimiter.
2. Maps different column names to the same fields (`Ordrenr`, `Order ID` and `order_id` are all the order number).
3. Parses Norwegian and English number and date formats.
4. Merges spelling variants of the same product.
5. Removes duplicate orders.
6. **Never drops data silently:** every row it cannot use goes to an *Issues* sheet with the file, the row number and the reason, so it can be fixed at the source.
7. Writes the report:
   - **Summary:** revenue, orders, units, average order value, revenue by month with a chart, top 5 products
   - **By product / By city / By channel:** totals and share of revenue
   - **Data:** all clean rows with a filter, ready for your own pivot tables
   - **Issues:** rows that were set aside, and why

Example output: [`examples/sales_report.xlsx`](examples/sales_report.xlsx)

```
> python -m salesreport data/raw -o examples/sales_report.xlsx
Read 446 rows from 3 files: orders_september_2026.xlsx, regnskap_ordre_2026-08.csv, webshop_orders_2026-07.csv
Used 417 rows, set aside 29 (reasons are on the Issues sheet)
Revenue 380 161 kr from 417 orders
Saved examples/sales_report.xlsx
```

## Run it (Windows)

Needs Python 3.10 or newer.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m salesreport data/raw -o sales_report.xlsx
```

Point it at your own folder of exports instead of `data/raw`. If your files use
other column names, add them to `COLUMN_ALIASES` in `salesreport/clean.py`.

## Tests

```
pip install pytest
python -m pytest
```

The tests cover number and date parsing, column mapping, duplicate handling
and a full run on the sample data.

## Structure

```
salesreport/
  clean.py    reading, column mapping, parsing, duplicates, issues
  excel.py    the formatted workbook and chart (openpyxl)
  cli.py      command line interface
tools/make_sample_data.py   generates the synthetic input files
tests/                      pytest tests
```
